# 猫游记游戏界面结构参考

> 数据来源：pet.jsp 主页面快照 + Pet.js 客户端脚本（555KB）逆向 + WinINET 缓存分析
> 游戏区整体尺寸约 900×640（主页面 body 内绝对定位布局，IE 内核）

## 一、整体架构

```
pet.jsp（主页面外壳）
├── 顶部状态条（HP/SP/经验）
├── petWin iframe（100% × 465px）—— 主视图区
│   ├── 地图/房间画面（0~450px 宽）
│   │   ├── 背景图（map.*.html 单图 或 切片表格）
│   │   ├── 地图点位 span（.pos 黄底标签）
│   │   ├── roomDescStr 房间描述（左上角）
│   │   ├── shopButton 功能按钮（右上角）
│   │   ├── npcList NPC 列表（右侧）
│   │   ├── playerList 玩家列表（右侧）
│   │   └── NPC 对话层（renPicBG 遮罩 + renPic 头像 + npcChatReader 对话框）
│   └── 格子消息（roomReader：追加到页面底部的流式消息）
├── chatReader 世界消息栏（右上方）
├── chatMyReader 私聊消息栏（右下方）
├── 输入区（inputid 文本框）
└── 各类弹窗（好友/信息/物品/排行/表情）
```

### NPC 列表项渲染（_getNpc）

```html
<dt id="npc_0">
  <a onclick="p.cmd('talk 0')">
    <font color=blue>猫隐村村长</font> 肥猫
    <img src=img/button/t.gif title=交谈>
    <img src=img/button/a.gif title=攻击>
  </a>
</dt>
```

- canTalk>=0：显示交谈按钮，点击发送 `talk <索引>`
- canTalk==-1：怪物，点击查看详情
- 死亡状态：名字变灰 #A1A1A1

### 玩家列表项渲染（_getUser）

```html
<dt id="user_1544576">
  <img src=/img/button/viptag.gif>
  <font color=green>龙巢</font> 果冻我果冻
  <img src=img/button/t.gif title=交谈>
  <img src=img/button/f.gif title=跟随>
  <img src=img/button/z.gif title=加为好友>
</dt>
```

- 点击名字（菜单模式）弹出操作条：查看 / 交谈 / 跟随 / 交易 / 切磋


## 七、交互流程总结

```
点击地图点位 → go() → cmd('gto 地名') → setRoom/addNpcs/addUser → 界面刷新
点击 NPC 名字 → cmd('talk 索引') → showRenPic + addNPCC → 遮罩+头像+对话
点击对话选项 → cmd('具体命令') → 功能窗口（商店/任务/赠品）
```
