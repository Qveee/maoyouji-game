# 切片 4 设计：战斗引擎（2026-09-20 用户已确认，待命开发）

> 状态：设计已批准，**等用户明确指令后才开始实施**。

## 已确认决策

1. **死亡复活**：死亡后传送至最近城市的「教堂」节点复活（牧野草原死亡 → 猫隐村 `jiaotang`）。
2. **MVP 死亡惩罚**：回教堂复活 + HP/SP 全恢复，无其他惩罚；装备耐久 -5% 留待切片 5 装备系统上线后补。
3. **逃跑不进 MVP**：靠 3 分钟平局脱战。**备忘**：将来实现逃跑时，成功率与双方等级差相关（玩家等级越高越容易逃）。
4. **战斗中技能**：点底部技能栏 → 强化下一次出手（替换普攻 + 消耗 SP）。默认预装 1 个职业基础技能：战士=强力打击、法师=火球术。

## 范围（依共识 v1.0）
- 牧野草原开放（38 格，解锁 `muye03` 出口）；野外相邻格移动（城市仍自由移动）。
- 每格随机刷怪（进入时惰性生成并落库）；点怪物 NPC 发起攻击。
- `monsters.json`：牧野草原怪物（绿毛虫/泡泡等，血量参考怪物血量大全，MVP 手写 5~6 种）。
- 数据库迁移 002：`battles` 战斗状态表（快照+时间线+指令，持久化）。
- 战斗结算器：纯函数 + 固定种子 RNG；惰性时间推进（服务器零定时器，轮询触发快进）；攻速间隔/前摇/CD 按真实秒。
- 3 分钟上限 → 不分胜负；胜利给经验（`character_monster_stats` UPSERT）；战斗外 HP/SP 惰性恢复。
- 前端：战斗覆盖层（双方血条/SP、立绘、飘字）+ 战斗中技能栏联动。

## 验收
- 固定种子单测：命中/闪避/暴击/控制/击杀/平局/经验结算。
- 浏览器实测：进草原 → 遇怪 → 打完一场（胜/败/平局三路）。
