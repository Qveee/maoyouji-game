## 1. 游戏概述

### 1.1 核心概念

玩家创建角色时**领养一只宠物作为自己的角色**，为其选择职业（战士 / 法师），带着它探索格子地图、打怪升级、学习技能、收集装备、完成任务，重现经典页游时代的社区与冒险体验。

### 1.2 核心玩法循环

```
创建角色（选宠物+职业） → 新手村做任务 → 打怪升级/学技能
        ↑                                      ↓
   领取任务 ← 组队/聊天/交易 ← 换装备/激活职业技能 ← 获得经验/金币/掉落
        ↓
解锁新地图（驿站传送/传送石） → 挑战精英怪与 BOSS
```

### 1.3 核心系统一览

| 系统 | 关键词 |
|---|---|
| 账号与角色 | 5 角色 / 账号，宠物即角色，战士 / 法师 |
| 属性系统 | 五维属性：力量、敏捷、体力、智力、精神 |
| 技能系统 | 基础技能 + 职业技能（激活制），技能书 |
| 装备系统 | 五档品质、12 部位、耐久度、套装特效 |
| 怪物系统 | 普通 / 精英 / BOSS / 任务怪 |
| 战斗系统 | 回合制，3 分钟上限，野外 PK |
| 社交功能 | 五频道聊天、跟随、组队、交易 |
| 任务系统 | 主线 / 支线 / 日常 / 其他 |
| 移动系统 | 城市自由移动、野外相邻格、驿站与传送石 |

## 2. 账号与角色

### 2.1 账号与角色数量

- 每个账号最多可创建 **5 个角色**。
- 每个角色对应**一只宠物**，角色 = 宠物本身（无副宠 / 捕捉系统）。
- 角色名全局唯一，创建后不可与其他角色重名。

### 2.2 角色创建流程

```
选择宠物类型 → 选择职业（战士 / 法师）→ 输入角色名 → 进入猫隐村出生点
```

- 职业在创建时选定，后续**不可更换**（转职系统暂不设计）。
- 战士与法师的差异：
  - **战士**：主属性力量，近战物理输出，使用刀 / 剑 / 枪 / 匕首 / 爪系技能。
  - **法师**：主属性智力，远程法术输出，使用暗 / 火 / 光 / 风 / 冰系技能。

### 2.3 宠物类型与初始特色

宠物类型以 `assets/原版参考/宠物/` 目录为准，共 17 种。**每种宠物的初始五维属性与升级成长系数不同**，形成手感差异；同职业下不同宠物只是成长倾向不同，不存在绝对最优。

| 宠物 | 定位 | 主成长属性 | 次成长属性 | 特色说明 |
|---|---|---|---|---|
| 猫（功夫猫） | 均衡型 | — | — | 五维均衡，无短板，全被动天赋型，新手友好 |
| 小木猴（灵猴） | 灵巧型 | 敏捷 | 智力 | 天生灵巧，初始敏捷最高，闪避见长 |
| 恶魔波利 | 力量型 | 力量 | 体力 | 初始力量高，爆发物理输出 |
| 天使波利 | 精神型 | 精神 | 智力 | 初始精神高，续航恢复能力强 |
| 包子 | 体力型 | 体力 | 精神 | 血厚耐打，生存向 |
| 土包子 | 力量型 | 力量 | 体力 | 初始力量与体力双高，偏坦克 |
| 蘑菇宝宝 | 智力型 | 智力 | 精神 | 初始智力高，法系苗子 |
| 火星人 | 敏捷型 | 敏捷 | 智力 | 敏捷智力双修，法系中的灵敏派 |
| 年兽 | 力量型 | 力量 | 敏捷 | 初始力量顶级，升级力量成长最高 |
| 沙地仙人掌 | 体力型 | 体力 | 敏捷 | 皮糙肉厚，防御向 |
| 水母 | 智力型 | 智力 | 体力 | 法术天赋高，血量也不弱 |
| 水獭 | 敏捷型 | 敏捷 | 力量 | 敏捷力量双修，物理灵敏派 |
| 小恶魔 | 敏捷型 | 敏捷 | 智力 | 灵动狡黠，闪避与法术兼备 |
| 熊宝宝 | 体力型 | 体力 | 力量 | 初始体力最高，血牛型 |
| 鸭嘴兽 | 均衡型 | 体力 | 敏捷 | 均衡偏生存，水陆两栖 |

### 2.4 宠物技能与种族天赋

每只宠物拥有独立的**宠物主动技能**（最多 1 个，年兽 2 个）与**种族天赋被动**（1~4 个）：

- **宠物主动技能**：战斗中手动释放，与职业技能共用技能快捷栏；存在职业限定（战士 / 法师 / 通用），角色职业不符则不可使用；统一消耗 35 SP（个别技能见详表备注）。
- **种族天赋（被动）**：始终生效，不受职业影响。
- 宠物技能独立于职业基础 / 职业技能体系（§4），无需技能书学习。

> 完整技能效果、职业限定、数据完整性说明见 `docs/宠物技能与种族天赋.md`。包子、土包子、火星人的技能数据待补充。

### 2.5 升级与加点

- 角色通过战斗与任务获得经验升级（经验公式见 §3.4）。
- 每次升级：宠物按自身成长系数**自动增长五维属性**（不同宠物不一致，见 §2.3）。
- 职业主属性额外 +1：战士每级力量额外 +1，法师每级智力额外 +1。

## 3. 属性系统

### 3.1 五维属性

| 属性 | 英文 | 作用 |
|---|---|---|
| 力量 | STR | 与战士攻击力挂钩：**1 力量 = 2 攻击力** |
| 敏捷 | AGI | 与闪避和防御挂钩 |
| 体力 | VIT | 与 HP 上限挂钩 |
| 智力 | INT | 与法师攻击力（法术强度）、SP 上限挂钩 |
| 精神 | SPR | 与 HP 恢复速度挂钩 |

### 3.2 其他属性（战斗面板）

| 属性 | 说明 |
|---|---|
| 伤害 | 武器 / 法术的基础伤害区间（如"7 - 9 伤害"） |
| 攻击力 | 面板攻击加成，直接参与伤害公式 |
| 防御力 | 降低受到的伤害 |
| 暴击 | 暴击概率（基础 5%），暴击时按暴击伤害倍率加成 |
| 暴击伤害 | 暴击时的伤害倍率（基础 150%，可被装备 / 被动提高） |
| 闪避 | 完全回避一次攻击的概率，有上限 |
| 攻速 | 攻击间隔（秒/次），主要由武器速度决定，可被被动 / 装备加成 |

### 3.3 派生公式（建议值，待平衡）

| 派生属性 | 公式 |
|---|---|
| HP 上限 | `50 + 体力 × 8 + 等级 × 10 + 装备 HP` |
| SP 上限 | `30 + 智力 × 5 + 等级 × 5 + 装备 SP` |
| 战士攻击力 | `力量 × 2 + 装备攻击` |
| 法师攻击力（法术强度） | `智力 × 2 + 装备法强` |
| 防御力 | `敏捷 × 1.5 + 装备防御` |
| 闪避率 | `敏捷 × 0.3%`（上限 40%） |
| 暴击率 | `5% + 装备/被动加成`（上限 60%） |
| 暴击伤害 | `150% + 装备/被动加成`（上限 300%） |
| HP 恢复（战斗内） | `每回合 1 + 精神 × 0.5` |
| HP 恢复（战斗外） | `每 5 秒 1 + 精神 × 0.5` |
| SP 恢复 | `每 5 秒 1 + 智力 × 0.2` |

### 3.4 升级经验

- 升级所需经验：`EXP(需) = 100 × 当前等级^1.5`（向下取整）。
- 等级上限：**90 级**（与世界地图最高练级场景 80-90+ 级对齐，见 §10.4）。

## 4. 技能系统

### 4.1 技能分类

| 分类 | 说明 | 获取方式 |
|---|---|---|
| 基础技能 | 战士 / 法师的职业通用技能，无系别限制 | NPC 学习 + 升级 |
| 职业技能 | 各武器系 / 法系的专属技能，**需先激活对应系别** | NPC 学习 + 升级 |
| 高阶技能 | 部分系别的高阶技能 | **只能通过技能书学习**（如"秘籍：舍命穿刺"） |

- 技能详表（等级、数值、CD、消耗、描述）以 `docs/技能书与对应技能表.xlsx` 为准，本文不复制明细。

### 4.2 职业分支

| 职业 | 分支系别 | 对应技能系（xlsx 口径） |
|---|---|---|
| 战士 | 刀、剑、枪、匕首、爪 | 飓风刀法、十字剑、霸王枪、龙葵匕刃、幽冥爪 |
| 法师 | 暗、火、光、风、冰 | 暗魔法、火系法术、圣魔法（光）、风系法术、冰系法术 |

- **跨系学习**：玩家可以在 NPC 处学习多个系别的技能（战士可学多种武器系，法师可学多种元素系），不受已学技能限制，只受等级与金币限制。
- 同一系别技能有等级（如"火球术【1级】~【23级】"），在 NPC 处消耗金币升级；**秘籍类技能书**可将技能突破到更高等级段（如"秘籍LV2：火球术"→ 23 级）。

### 4.3 基础技能清单（职业通用）

| 职业 | 技能系 | 技能（基础等级） |

| 战士 | 战士通用 | 强力打击、猛抽、致命一击 |
| 法师 | 法师通用 | 唤醒、沉默、火球术、魔法盾 |

### 4.4 职业技能系别与技能一览

| 技能系 | 职业 | 技能 |

| 飓风刀法 | 战士·刀 | 嗜血、怒风之击、怒风斩杀、残影刀、猛禽一击 |
| 十字剑 | 战士·剑 | 十字斩、撕裂、压制、圣盾、盾牌猛击、剑气四方 |
| 霸王枪 | 战士·枪 | 破驽枪、破除护甲、舍命穿刺、横扫、银枪乱舞（终极） |
| 龙葵匕刃 | 战士·匕首 | 伏击、凿击、脚踢、生命消散、龙葵连刺 |
| 幽冥爪 | 战士·爪 | 出血、冥火爪、心神不宁、空手入白刃 |

| 火系法术 | 法师·火 | 火球术（通用表内）、烈焰灼烧、火焰屏障、炎爆术、龙息 |

| 冰系法术 | 法师·冰 | 寒冰箭、冰霜新星、寒冰护体、分身 |

### 4.5 职业技能激活机制（核心规则）

1. **释放任何职业技能前，必须先"激活"对应系别**（如激活"剑"才能释放十字剑系技能）。
2. **同一时间只能激活一个系别**：激活"刀"后，无法释放剑系技能，需先切换激活。
3. **激活即获得该系职业被动**（示例：激活剑系获得"+X% 暴击"）。职业被动在切换激活后立刻失效，由新系被动替代。
4. 基础技能（职业通用）不受激活限制，随时可释放。
5. 战斗中**禁止切换激活系别**；切换仅可在非战斗状态进行。
6. 激活状态在角色信息栏醒目显示（如"已激活：剑 · 十字剑"）。

各系职业被动（建议值，待平衡）：

| 系别 | 职业被动 | 系别 | 职业被动 |
|---|---|---|---|
| 刀 | 攻击速度 +10% | 暗 | 法术穿透 +10% |
| 剑 | 暴击率 +5% | 火 | 法术强度 +5% |
| 枪 | 攻击力 +5% | 光 | SP 恢复 +50% |
| 匕首 | 闪避率 +5% | 风 | 闪避率 +5%，攻速 +5% |
| 爪 | 暴击伤害 +15% | 冰 | 受到伤害 -5% |

### 4.6 技能字段规范

每个技能在详表（xlsx）中包含以下字段，实现时以此为准：

| 字段 | 说明 | 示例 |
|---|---|---|
| 前摇 | 咏唱 / 施法时间（秒），"/"表示瞬发 | 破除护甲 1.5 秒 |
| CD | 冷却时间（秒） | 猛抽 30 秒 |
| 控制时长 | 昏迷 / 沉默等控制秒数 | 猛抽昏迷 3 秒 |
| 描述 | 含数值、SP 消耗的完整说明 | "造成最多 50 点伤害并昏迷 3 秒（消耗 10SP，冷却 30 秒）" |

## 5. 装备系统

### 5.1 装备品质

**灰色 < 绿色 < 蓝色 < 紫色 < 橙色**

- 品质越高，同等级装备属性上限越高（同等级装备中，蓝 > 绿 > 灰）。
- 品质通过名称 / 边框颜色区分：灰色（粗制）、绿色（优秀）、蓝色（精良）、紫色（史诗）、橙色（传说）。
- 装备属性与出处详表见 `docs/猫游记蓝宝书.doc` 第二篇"装备属性及出处"（武器类：剑、枪、匕首、爪、刀、魔杖、盾牌、圣物；穿着类按等级 1-75+ 分档）。

### 5.2 装备部位

| 部位 | 数量 | 说明 |
|---|---|---|
| 头、肩、胸、手套、腰带、护腿、鞋子、护腕 | 各 1 | 基础穿戴部位 |
| 戒指 | 最多 **2** 枚 | 两个戒指栏位 |
| 项链、披风 | 各 1 | 饰品部位 |
| 主武器 | 1 | 攻击类武器（战士：刀/剑/枪/匕首/爪；法师：魔杖） |
| 副手 | 1 | 盾牌、法典 |

- **双手武器规则**：如果穿戴的是双手武器，则**不能穿戴副手装备**（主武器占用副手栏位）。
- 法师主武器为魔杖；战士主武器为刀 / 剑 / 枪 / 匕首 / 爪（与技能系别对应，但穿戴武器不限制学习技能，只影响**激活与释放对应系技能**的合理性——激活某系时建议装备同系武器，见 §4.5）。

### 5.3 穿戴等级要求

- 每件装备标注 `装备需要：等级 N`，角色等级不足不可穿戴（蓝宝书口径，如"装备需要: 等级:5"）。
- 穿戴等级越高的装备基础属性越高。

### 5.4 耐久度

- 每件装备有耐久度上限（如"耐久: 14 / 17"），耐久随战斗损耗。
- **玩家被击杀**：身上穿着的所有装备耐久度 **-5%**（按上限取整）。
- **战斗损耗**：每进行 10 场战斗，身上装备耐久 -1 点（建议值，待平衡）。
- 耐久为 0 时装备属性**失效**（不消失），可在 NPC 处修理恢复；修理费用与品质、等级正相关。

### 5.5 装备属性格式（与蓝宝书对齐）

```
名称（出处：地图——怪物）
——部位，类型，X - Y 伤害，速度 Z，每秒伤害: D，耐久: a / b，属性加成，装备需要: 等级: N
```

示例：`步兵剑（出处：牧野草原——草原蝎）——右手，剑，7 - 9 伤害，速度 2.1，每秒伤害: 3.8，耐久: 13 / 13，装备需要: 等级: 4`

### 5.6 套装系统

- 装备存在**套装**（同名系列，如"灵猴""树灵""波力猎手""怒爪"等）。
- 集齐指定件数激活**套装特效**（属性加成或特殊效果）。
- 套装件数档位建议：2 件 / 4 件 / 6 件（具体套装与特效待数值阶段设计，沿用原版系列命名）。

## 6. 怪物系统

### 6.1 怪物分类

| 类型 | 名称前缀 | 行为 | 说明 |
|---|---|---|---|
| 普通怪物 | 无前缀 | **只会普通攻击（平 A）** | 野外主力经验来源 |
| 精英怪 | `精英·` 前缀 | 可释放技能 | 血量、攻击高于同级普通怪 |
| BOSS 怪 | `BOSS·` 前缀 | 可释放技能，带专属技能组 | 高级挑战目标，掉落高品质装备 |
| 任务怪 | 与任务绑定 | 与普通怪一致 | 仅任务相关时出现 / 有效 |

### 6.2 怪物属性与克制

- 怪物具有等级、种族 / 体型（如"动物·中型""昆虫·小型"，见怪物表"克制"列）。
- 怪物血量存在**区间浮动**（如 1-3 级泡泡 HP 20~40），同类怪每次刷新在区间内随机。
- 血量与掉落详表以 `docs/猫游记怪物血量大全.xlsx`（292 条）为准；怪物掉落装备出处亦见蓝宝书第一篇"怪物详细等级、所在地点、掉落装备"。

### 6.3 刷新规则（建议）

- 普通怪：被击败后 30 秒内在原区域刷新。
- 精英怪：3 分钟刷新。
- BOSS 怪：15 分钟刷新。
- 任务怪：随任务进度出现，不参与常规刷新。

## 7. 战斗系统

### 7.1 战斗形式

- **回合制自动战斗**：双方自动交替出手，玩家点击底部技能栏释放技能强化行动（原型：`测试/游戏主界面.html` 战斗覆盖层）。
- 战斗数值按 §3 公式计算：出手时结算命中 → 闪避 → 暴击 → 伤害（`武器/法术伤害区间 + 攻击力 - 防御减伤`）。
- 战斗节奏由攻速决定行动间隔；控制技能（昏迷 / 沉默）可打断与延迟行动。

### 7.2 战斗时长上限

- **每场战斗不超过 3 分钟**；超过 3 分钟未分出胜负则判定为**"不分胜负"**，双方脱离战斗，无奖励、无死亡惩罚。

### 7.3 玩家对战（PK）规则

1. **野外 / 比武场**：玩家可以向其他玩家发起攻击（PK）。
2. **城市安全区**：城市内除**比武场**外均为安全区域，无法对玩家发起攻击。
3. **战斗保护**：玩家在野外与怪物战斗时，其他玩家**无法对该玩家发起攻击**。
4. **多人围攻**：多名玩家允许对同一名玩家同时发起攻击（多 vs 一不限制）。
5. 玩家被击杀：佩戴装备耐久 -5%（见 §5.4），并回到最近城市的复活点。

### 7.4 战斗结算

- 胜利：获得经验、金币、掉落（按怪物掉落表）。
- 失败（PVE）：不损失经验，装备耐久 -5%，回城复活。
- 不分胜负：无得失，双方脱战。

## 8. 社交与基本功能

### 8.1 聊天系统

| 频道 | 可见范围 | 显示窗口 | 限制 |
|---|---|---|---|
| 私聊 | 指定的某个玩家 | 私人信息窗口 | — |
| 区域聊 | 当前格子的所有玩家 | 私人信息窗口 | — |
| 公会聊 | 全体公会成员 | 私人信息窗口 | — |
| 世界聊 | 全部玩家 | **世界 / 系统消息窗口** | **每玩家每 10 秒可发 1 条** |
| 队伍聊 | 队伍成员 | 私人信息窗口 | — |

- **世界聊**独占"世界 / 系统消息"窗口；其余频道均进入"私人信息"窗口。
- 区域聊、公会聊、队伍聊使用**不同字体 / 颜色**区分（建议：区域=默认宋体黑色，公会=绿色，队伍=蓝色）。
- 聊天输入区位于界面右侧，频道下拉选择：区域 / 世界 / 私聊 / 公会 / 队伍。

### 8.2 跟随

- 点击目标玩家的**跟随**按钮，即可跟随该玩家移动。
- 跟随期间自动复制目标的移动路径；玩家任意主动移动操作即解除跟随。

### 8.3 组队

1. 点击目标玩家的**组队**按钮，向其发送组队申请。
2. 对方**确认**后队伍成立，**邀请方为队长**。
3. **只有队长可以邀请**其他人入队（队员无邀请权限）。
4. 队伍成员可随时通过**"查看玩家位置"**按钮查看其他队员的当前所在格子。
5. **队长退出队伍时，队伍直接解散**（不转让队长）。
6. 队伍信息在"队伍列表"窗口展示（队员名、等级、职业、所在位置）。

### 8.4 交易

1. 向目标玩家申请交易，对方确认后进入交易窗口。
2. 双方放入交易道具、金币后点击**确认**。
3. **确认后交易内容（道具、金币）不可改变**；若任何一方调整了交易内容，则确认状态失效，需要**双方重新确认**。
4. 双方全部确认后交易立即生效，道具与金币互换。

### 8.5 其他玩家交互按钮

玩家列表 / 点击玩家弹窗提供：交谈（私聊）、跟随、加好友、组队、交易、攻击（野外）——与原版按钮（t/f/z 图标）及 `assets/原版参考/图标/` 对应。

## 10. 移动与世界地图

### 10.1 移动规则

| 场景 | 移动方式 |
|---|---|
| 城市内 | 可以**大范围移动**（点击城内任意已解锁格子直接前往） |
| 野外 | **只能行走在相邻的格子**（每次移动一格） |

- 世界由相互连接的格子（地点）组成；格子与地名坐标沿用原版地图点位（参考 `prototype/样式参考-猫隐村/`）。

### 10.2 驿站传送

- 每个城市都有**驿站**。
- 玩家与驿站 NPC **"专用空姐"** 对话，可以前往已解锁的对应城市（城市间快速传送）。
- **专用空姐还可设置传送保存点**（与传送石联动，见 §10.3）。

### 10.3 传送石

- 传送石是玩家**初始就有的道具**（不可丢弃）。
- 使用传送石可传送到**已保存的传送点**。
- 传送点在驿站由"专用空姐"设置 / 更新（同一时间保存一个，后设覆盖前设）。


### 11.2 区域明细

| 区域 | 内容 |
|---|---|
