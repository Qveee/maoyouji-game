## 二、任务分类体系

官网攻略把任务体系分为三大板块，板块下再分子类：

1. **主线任务**：按等级段推进（10~20、21~30、31~40、41~50、51~60、61~70、70~80 级分档）。
2. **支线任务**：同样按等级段组织。
3. **其他任务**：
   - 区域系列任务：通吃岛系列（60/80 级）、银月帝国系列（70~80 级）；
   - 每日任务：每天刷新一次；
   - 关系有关的任务：提升阵营/势力关系值；
   - 合成有关的任务：提升生产技能熟练度；
   - 各等级段任务：10~19、20~29、30~39、40~49、50~59、60~70 级各一条线；
   - 跑环任务：限时开放的多环连续任务链。

## 三、单条任务的标准数据结构

官网每条任务遵循固定格式，本质上是一张字段化任务表：

```
[等级] 任务名
起始：地图的NPC
结束：地图的NPC
流程：具体步骤描述
奖励：经验、货币、关系值、装备等
```

字段说明：

| 字段 | 说明 |
|---|---|
| 等级 | 接取等级门槛，写在任务名前的方括号内 |
| 任务名 | 唯一名称，中文 |
| 起始 | 发任务的 NPC 及其所在地图（精确到子场景） |
| 结束 | 交任务的 NPC 及其所在地图，可与起始相同 |
| 流程 | 打怪、收集、送信、使用道具、对话中转等步骤描述 |
| 奖励 | 经验默认有（攻略惯例省略不写），特殊奖励单独注明 |

原版实例（跑环任务 20~29 级第一环）：

> [25] 修行之路  
> 起始：拖把城广场的创造者  
> 结束：猫隐村广场小道的老赵  
> 流程：找老赵对话

## 四、各类任务机制细节

### 4.1 主线 / 普通任务

- 以 NPC 对话链为主：起始 NPC → 中转 NPC（传递任务道具如包裹、信件、印章）→ 交还 NPC。
- 混合打怪目标，例如「到通吃岛打通吃岛棍使和通吃岛棒使，得到通吃棒，再找韦铜锤交任务」。
- 部分任务需使用任务道具触发战斗或变身，例如「猫毛拂尘」用于解除诅咒、召唤七夫人逐个战斗。
- 主线按等级分档串联地图：10~20 级主线第一环为 `[10] 拜会元太公`（起始：猫隐村广场的戈多 → 结束：猫隐西村学堂的元太公）。

### 4.2 每日任务

- 每个等级段一条任务线，如 30~39 级「白马港的威胁」：打 15 个沙魔 → 奖励经验 + 50 银币。
- 关键规则：**角色等级越高，任务给的经验越少**（经验衰减机制）。
- 任务道具在 NPC 对话时自动使用，无需手动操作。

### 4.3 关系任务

- 交付材料或打怪，奖励势力关系值：银月帝国 +50、静静蕃薯团 +50、镖局 +50、猫隐村 +50、希望码头 +500。
- 关系值是任务线前置条件：银月帝国系列需「银月关系达到尊敬」才能接取。
- 个别关系任务不限次数：「希望码头秘宝」可无限做（打怪随机掉恶魔果实），单次奖励希望码头关系 +500。

### 4.4 合成任务

- 典型例子：锻造每日任务，找拖把城钢铁大师按要求交付物品，奖励锻造术熟练度 +50。
- 定位是把任务系统与生产技能熟练度挂钩。

### 4.5 跑环任务

- 20~29 级跑环：每天 **12:00~18:00** 可领取一次。
- 一条约 10 环的连续任务链（修行之路 → 元太公的扇子 → 雪原城之旅 → 刀客的试炼 → 骄傲的卫兵 → 魂魄精华的归宿 → 证明实力 → 团长的背包 → 推荐信 → 应得的奖励），中途跨越多个城市。
- 整线做完才给总奖励：经验 +15500。

### 4.6 区域解锁型系列任务

- **通吃岛**：先做 [60] 拖把通行证 → 收集印章 → 通吃岛欢迎你 → 给老船长的世界碎片（交 5 个世界碎片，此后可随时进出通吃岛）；再做 [80] 系列（收集猫毛、圣拖把、雪原城之宝、世界树枝条等）合成「猫毛拂尘」解除诅咒；最后解锁韦府 Boss 战——打败韦小宝后被传送到神龙岛，击败神龙教地狱大将军后奖励装备二选一（英雄勋章/英雄饰物）。
- **银月帝国**：前置条件为银月关系达到尊敬；官方建议 5 人组队，最终任务建议 2 个五人队轮番打；70~80 级连续推进（帝国的试炼 → 试炼①~⑧ → 最后的试炼 → 成为银月战士 → …），最终奖励装备二选一（不可撼动之物/新月之短杖 选一）。

### 4.7 职业技能任务

- 高阶职业专精技能通过任务习得，各专精均为同构链：「接任务 → 打指定怪掉任务物品 → 交任务学技能」。
- 实例：
  - 剑系「十字剑」：雪原城银光骑士团找骑士统帅接任务 → 低矮林地打草原流氓掉宝箱钥匙 → 交任务学会；
  - 刀系「飓风刀法」：雪原城酒馆找狂风刀客接任务 → 打草鸡得草鸡肉 → 交酒馆老板换「老酒」→ 交任务学会；
  - 火系「火系法术」：雪原城魔法研究院找炎之魔导士 → 低矮林地打草原强盗掉火焰符文 → 交任务学会。
- 匕首、枪、刀、爪、五系法师（火/冰/风/圣/暗）专精均有同类任务。

## 五、奖励设计规律

| 规律 | 说明 |
|---|---|
| 经验为基线 | 经验默认所有任务都有，低价值任务仅给经验 |
| 货币随等级段增长 | 每日任务奖励 10 银币（10~19 级）→ 1 金币（50~59 级） |
| 装备二选一 | 高难度系列任务用「A/B 选一」提供职业定向选择 |
| 关系值/熟练度 | 与阵营声望、生产技能成长挂钩，形成长线日常动力 |
| 技能/称号 | 高阶职业专精技能必须通过任务解锁 |
| 经验衰减 | 每日任务对高等级角色给更少经验，抑制无脑刷日常 |
| 限时窗口 | 跑环任务限制领取时段 + 每日一次，控制产出 |

## 六、对《喵游记》任务系统的对照

与 `docs/游戏规则设计.md` 第 10 章和 `docs/清单/任务清单.md` 的现状对照（仅供参考，不改动任何清单）：

| 维度 | 原版《猫游记》 | 《喵游记》现行设计 | 可借鉴点 |
|---|---|---|---|
| 任务类型 | 主线、支线、其他（区域系列/每日/关系/合成/等级段/跑环） | 主线、支线、日常、周常、成就 | 跑环（限时多环链）与关系任务可作为后期扩展方向 |
| 数据结构 | [等级]+名称+起始+结束+流程+奖励 | 任务清单已含 ID/类型/开始与结束 NPC/接取条件/目标/对话/奖励/备注，粒度更细 | 现行结构已覆盖原版全部字段，无需调整 |
| 前置条件 | 等级、前置任务、关系值（尊敬） | 等级 + 前置任务 | 关系值门槛可待声望系统引入后补充 |
| 奖励结构 | 经验基线 + 货币 + 关系值 + 熟练度 + 装备二选一 + 技能 | 经验 + 金币 + 道具/装备/称号/钻石 | 装备二选一、熟练度奖励可作 Boss 级任务与生产系统的联动参考 |
| 防肝机制 | 日常经验衰减、跑环限时窗口、每日次数限制 | 每日/每周刷新 | 若后期日常产出失衡，可参考经验衰减思路 |
