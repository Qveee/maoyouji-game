# MVP 切片 1：工程脚手架 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立自包含 monorepo（Fastify + Vue 3 + MySQL 8），完成 schema 改造版迁移文件与可跑绿的测试基线。

**Architecture:** pnpm monorepo，`server/`（Fastify + TS + mysql2）、`web/`（Vue 3 + Vite）、`db/migrations/`（顺序 SQL）、静态数据目录 `server/data/`（本切片仅占位，切片 3 起填充）。MySQL 仅存运行时状态；所有原 `cfg_` 表移出数据库。

**Tech Stack:** TypeScript、Fastify、mysql2、Vue 3、Vite、Vitest、pnpm、Docker Compose（仅 MySQL 8.0）。
