# 宠物技能与种族天赋

> **配套文档**：本文档是《游戏规则设计》§2 宠物系统的配套详表，收录各宠物的**主动技能**与**种族天赋（被动）**。
> **数据来源**：原版《猫游记》宠物技能设定整理。
> **命名对齐**：宠物名以 `assets/原版参考/宠物/` 素材为准（括号内为资料别名）。

---

## 一、技能体系说明

1. **宠物主动技能**：每只宠物最多 1 个（年兽 2 个），战斗中手动释放，与职业技能共用底部技能快捷栏。
2. **种族天赋（被动）**：每只宠物 1~4 个，**始终生效**，不受职业影响、不可卸下。
3. **职业限定**：宠物主动技能存在职业限定（战士 / 法师 / 战士与法师通用）。创建角色时若职业与技能限定不符，该宠物主动技能**不可使用**；种族天赋不受影响。
4. **SP 消耗**：宠物主动技能统一消耗 **35 SP**（部分技能原文未标注消耗，以"未标注"注明，待补充核实）。
5. 宠物技能独立于职业的基础技能 / 职业技能体系（见《游戏规则设计》§4），学习不需要技能书。
