# 《喵游记》开发共识（2026-09-19 三轮设计拷问定稿）

## 范围
1. MVP = 单机核心循环：注册 → 建角色（17 宠物 + 战士/法师）→ 猫隐村/牧野草原走格子 → 打怪 → 掉落 → 背包装备 → 新手任务 → 升到 10 级。聊天/组队/交易/PK/公会/好友/队伍/商城/BOSS 全部二期。
2. MVP 技能只含基础技能 + 剑系（战士）、火系（法师）各一条职业技能线。
3. 素材缺失的宠物（星尾龙）可配置但暂不可选；BOSS 数值缺口不挡 MVP。
4. 死亡后在最近城市的「教堂」复活（切片 4 起）；MVP 死亡惩罚仅 HP/SP 全恢复，装备耐久 -5% 留切片 5。
5. 逃跑不进 MVP（3 分钟平局脱战）；将来实现时成功率与双方等级差相关。

## 架构
4. 静态数据进仓库文件：`server/data/*.json` 按域拆分（宠物/道具/装备/怪物/技能/地图/NPC/任务/等级），字符串 code 主键；zod 校验 + 启动时交叉引用检查，不过则拒绝启动。
5. MySQL 只存运行时状态：schema 删除全部 cfg_ 表，原引用列改 VARCHAR code（应用层兜底），运行时表间物理外键保留。
6. 战斗惰性结算：状态持久化、服务器零定时器，前端 1s 轮询触发时间线快进，技能 = POST 指令，3 分钟上限在结算时判定；战斗外 HP/SP 恢复按 updated_at 时间差惰性补算。
7. 战斗结算器纯函数化 + 固定种子 RNG 可测。

## 技术栈
8. 后端 Fastify + TS + mysql2 手写 SQL（无 ORM）。
9. 前端 Vue 3 + Vite + TS（复刻原型视觉，数据全走 API）。
10. pnpm monorepo / Vitest / ESLint + Prettier / 零 CDN 零运行时联网。
11. 认证：用户名 + 密码（argon2id）+ httpOnly cookie session（JWT 实现），无邮箱无找回。
12. docker-compose 只跑 MySQL 8.0.16+，server 本机 pnpm dev。
