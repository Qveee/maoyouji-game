# 聊天系统设计（2026-09-20 定稿）

> 面向后续维护者的聊天系统说明。流程性设计过程见 `docs/superpowers/specs/2026-09-20-chat-design.md`。

## ① 频道总览

| 频道 | 可见范围 | 显示窗口 | 字体颜色 | 状态 |
|---|---|---|---|---|
| 区域聊 | 同一地图格子（节点）内的所有玩家 | 私人信息窗 | `#363A3C` 深灰 | ✅ 开放 |
| 世界聊 | 全服所有玩家 | 世界窗 | 默认墨色 | ✅ 开放（限频） |
| 私聊 | 指定的某一名玩家 | 私人信息窗 | `#058306` 绿 | ✅ 开放 |
| 队伍聊 | 队伍成员 | 私人信息窗 | `#8B4513` 褐色 | 🔒 预留（队伍系统二期） |
| 公会聊 | 公会成员 | 私人信息窗 | `#5991CA` 蓝 | 🔒 预留（公会系统二期） |

- 颜色均为用户指定色值（2026-09-20）；队伍「褐色」未给色值，暂取标准 saddle brown `#8B4513`，可调。
- 世界窗即右上面板（原「世界·掉落公告」改名「世界」），世界聊与后续掉落公告共用；其余频道一律进「私人信息」窗。
- 左下「聊天记录」面板只收系统消息（欢迎语、移动失败、发送报错等），不承载聊天。

## ② 消息模板与命名样式

**私聊模板**（用户指定）：

| 视角 | 模板 | 示例 |
|---|---|---|
| 我是发送方 | `你 对 {目标名} 说: {内容}` | <span>你 对 喵小游 说: 你好</span> |
| 我是接收方 | `{发送名} 对 你 说: {内容}` | 喵小游 对 你 说: 你好 |

- 玩家角色名统一带**下划线**（CSS 类 `.name`，`text-decoration: underline`）。
- 「你」字固定用红色 `#F52627`。
- 区域/世界消息格式为 `名字：内容`（全角冒号）。
- 所有消息行均带 `<time>` 时间前缀（数据库存 UTC，前端 `toLocaleTimeString` 转浏览器本地时间）。
- 前端按结构化字段（senderName / targetName / content）拼装渲染，**不在数据库存预拼字符串**——样式升级不需要迁移历史数据。

## ③ 业务规则

1. **世界聊限频**：每角色每 10 秒只能发一条；超频返回 400「世界频道每10秒只能发言一次」。校验为惰性实现（发送时查上一条世界消息时间差），服务器零定时器（开发共识 §6）。
2. **区域聊路由**：按 `characters.current_node_code` 判定同格；玩家移动后自动只看得到新格子的区域消息。
3. **私聊目标**：手输对方角色名（角色名全服唯一、未软删）；目标不存在 404，私聊自己 400。
4. **消息生命周期**：落库 MySQL；发送世界消息时顺带惰性清理 1 天前的旧消息。
5. **预留频道**：队伍/公聊的频道枚举与显示路由已预置，等对应成员系统上线后，把「成员可见性过滤」接入 `GET /messages` 即可；下拉框中置灰禁用（`<option disabled>`）。

## ④ 数据模型（db/migrations/002_chat.sql）

表 `chat_messages`：

| 列 | 类型 | 说明 |
|---|---|---|
| id | BIGINT UNSIGNED PK | 自增，前端轮询游标 |
| channel | ENUM('area','world','private','guild','team') | guild/team 预留 |
| sender_id | BIGINT UNSIGNED NOT NULL | 发送者角色 id |
| sender_name | VARCHAR(32) NOT NULL | 发送时名字快照（免 join） |
| target_id / target_name | BIGINT UNSIGNED / VARCHAR(32) NULL | 私聊专用 |
| node_code | VARCHAR(64) NULL | 区域聊专用 |
| content | VARCHAR(60) NOT NULL | 与前端 maxlength=60 一致 |
| created_at | DATETIME(0) UTC | 落库 UTC，展示转本地 |

索引：`(sender_id, channel, created_at)` 限频查；`(node_code, id)` 区域轮询；`(target_id, id)` 私聊轮询。

## ⑤ API（server/src/routes/chat.ts，前缀 /api/chat，需选角）

- `GET /messages?sinceId=N` — 带 sinceId 返回 `id > N` 的对我可见消息（升序）；不带返回最新 50 条可见消息。可见性：world 全员；area 同节点；private 双方。
- `POST /send {channel, content, targetName?}` — 校验失败返回 400/404 + `{message}`，前端把报错以系统消息形式提示到「聊天记录」。

## ⑥ 前端行为（web/src/components/GameShell.vue）

- 进入游戏拉一次历史，之后每 3 秒 `sinceId` 增量轮询；组件卸载清理定时器。
- 发送成功**不本地回显**，消息经轮询统一到达（发送者自己也能看到自己的消息，与他人一致）。
- 选「私聊」频道时，输入行左侧出现目标角色名输入框（maxlength 32）。
